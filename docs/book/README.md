# Delta Robot Sorting Project book

[Open the 34-page PDF](Delta_Robot_Sorting_Project_Guide.pdf).

A practical guide to the existing workcell, ROS 2 connections and robot control, camera perception, operation, configuration, troubleshooting, and future extensions. It includes actual project renders, explanatory diagrams, a clickable contents page, and a glossary.

The PDF has selectable text, embedded fonts, and page bookmarks. Clicking a page footer returns to the contents.

[Plain-text companion](Delta_Robot_Sorting_Project_Guide.md) preserves the explanations and commands for easy searching. Diagrams are in the PDF.

Edition: 24 September 2026. Existing code, configuration, source CAD, generated assets, tests, and technical documents were not changed. Previously recorded simulation results are identified as such; generating this book did not rerun the robot.
